# Claude Code Preview Mod implementation plan

> Use subagent-driven-development, TDD, and independent task reviews. Latest user instructions override the old remote-first plan.
**Spec:** docs/superpowers/specs/2026-10-03-claude-code-preview-mod-design.md
**Goal:** native Claude Code TUI Markdown/image/video/composer-paste preview with SSH byte transport.

## Global constraints

- Worktree `<worktree>`.
- User already authorized implementation and Subagent-driven execution; do not repeat approval gates for routine choices.
- Root plugin name claude-code-preview-mod, no MCP requirement or runtime network listener.
- TypeScript, Yarn, Node stdlib helper, already-installed ffmpeg/ffprobe.
- Mod runtime types generated by Claude 2.1.288 are authority.
- No shell interpolation; root canonicalization and identity-checked bounded reads. Decode protocols file,pipe only.
- Send image bytes through native Image/UI methods, preserve prompts/tool content.
- Markdown 2 MiB, static images 32 MiB, video 2 GiB, max frame 640×360, 8fps, max 600 seconds.
- Playback controls + decoder cleanup. v1 muted is disclosed; do not claim full audio.
- Composer-before-submit paste preview uses the verified 2.1.288 current-session cache adapter and must disclose that it is an internal version-dependent contract.
- Pause if runtime cannot meet an essential UI requirement; implement independent feasible parts and explain exact gap.
- Nothing in other projects, no global plugin install, no public publishing.
